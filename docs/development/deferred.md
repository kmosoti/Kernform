# Deferred after 0.1.0

The following work is intentionally absent from the frozen 0.1.0 contract:

- remote repository creation, pushes, merge automation, branch protection, or forge administration
- plugin loading, arbitrary capability scripts, generalized template packs, or LLM-driven planning
- HTMX, browser WebAssembly, authored JavaScript, Node, or frontend build pipelines
- Kubernetes, cloud resources, deployment environments, or production service operation
- additional CI providers or maintenance-branch automation
- non-Linux release baselines and multi-architecture OCI publication
- automatic credential management or long-lived publication credentials

These are not partial implementations or hidden flags. Adding one requires an explicit future
contract, dependency review, threat model, tests, and versioning decision.
