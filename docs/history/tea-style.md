# Pre-reform repository history

## Status

Historical.

## Original purpose

Before Kernform, this repository was named `tea-style` and stored Typed Encapsulated Architecture
doctrine as a Markdown knowledge graph. A bounded Python tool named `tea_kb` validated, indexed,
reported, and visualized that graph.

## Preserved concepts

Kernform retains the durable engineering constraints that mutation should be explicit, typed,
observable, replay-safe, and bounded by ownership. Those ideas now govern executable project
lifecycle behavior rather than a doctrine graph.

## Discarded active structures

The knowledge-base nodes, domain doctrine trees, generated graph artifacts, graph-specific CI, and
the lifecycle package are not part of the active Kernform product. They remain available through
Git history rather than a permanent legacy directory.

The local annotated tag `tea-style-final` identifies the exact final pre-reform commit. Publication
of that tag is a separate repository-delivery action.
