# Repository scope

## Purpose

Kernform creates and maintains deterministic local Python/Rust project structures.

## In scope

- versioned manifest, state, plan, command, diagnostic, and ownership contracts
- pure planning and conformance evaluation
- controlled local filesystem, process, Git, provider, transaction, and container effects
- installable Python API and CLI backed by a private PyO3 adapter
- composable signatures, declarative capabilities, templates, Podman assets, and Nushell surfaces
- generated reference projects, test tiers, CI intent, and immutable release evidence

## Out of scope

- hosted services or production APIs operated by this repository
- forge repository creation, pushes, branch protection, or deployment management
- plugins, arbitrary scripts, shell-command interpolation, or LLM-driven initialization
- Node, authored browser JavaScript, Kubernetes, or cloud deployment
- compatibility support for the pre-reform runtime
